ROGX is an enterprise-grade conversational AI engine built using the **Botpress** platform. It combines robust Natural Language Understanding (NLU) with advanced workflow automation to deliver intelligent, multi-turn user experiences. This project demonstrates practical expertise in conversational architecture, state management, and external API orchestration.

🚀 Key Technical Highlights for Recruiters
Advanced Workflow Automation: Engineered complex visual flows, transition conditions, and state variables to manage non-linear, deep conversations smoothly.
Custom Code Execution:** Utilized Custom JavaScript/TypeScript Execute Code cards within Botpress to handle complex data manipulation and dynamic payloads.
API & Webhook Orchestration: Integrated external REST APIs to fetch real-time data, pushing the bot's capabilities beyond static scripts into dynamic automation.
* **Omnichannel Readiness:** Architected with a deployment-ready mindset, easily adaptable for Webchat, WhatsApp, or Discord integrations.

 Tech Stack:
* **Platform:** Botpress Cloud
Backend Scripting: JavaScript / TypeScript (Node.js environment)
Integrations: REST APIs, JSON Webhooks
